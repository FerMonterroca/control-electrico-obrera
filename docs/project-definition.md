# Definición del proyecto

## Qué es

Control Eléctrico Obrera será una plataforma web para un negocio de material eléctrico industrial ubicado en la colonia Obrera, Ciudad de México. Busca generar ventas mediante presencia orgánica, atención de solicitudes comerciales y herramientas digitales para clientes y personal interno.

## Objetivo

Construir progresivamente un canal digital mantenible que permita descubrir productos, solicitar materiales y cotizaciones, atender empresas y facilitar el contacto con el negocio.

## Alcance previsto del MVP

El MVP futuro contempla catálogo de productos, SEO, cotizaciones, búsqueda de materiales especiales, atención a empresas, contacto mediante WhatsApp y un panel administrativo proporcionado al alcance real.

## Alcance de esta etapa

Esta etapa entrega la base técnica y la primera experiencia pública: monorepo, frontend Astro, API ASP.NET Core, EF Core, PostgreSQL local, catálogo de solo lectura, páginas de producto, navegación por marcas y categorías, filtros, contacto por WhatsApp, health checks, manejo base de errores, CORS y documentación para desarrollo.

## Fuera de alcance por ahora

No se implementan cotizaciones persistidas; autenticación; panel administrativo; cuentas de cliente; almacenamiento S3; cargas de archivos; inventario en tiempo real; comercio electrónico; pagos; sitemap; SEO avanzado; Google Maps ni cotizador automático. Los modelos para futuras cotizaciones y usuarios administrativos existen en la base de datos, pero todavía no tienen flujos públicos ni administrativos.
